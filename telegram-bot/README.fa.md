# ربات تلگرام Market Analyzer — مخصوص گوشی

این نسخه به‌جای APK از طریق پیام‌های تلگرام قیمت و تحلیل می‌دهد.

## منبع قیمت و محدودیت‌ها

- **مستقیماً به حساب شخصی LiteFinance یا MetaTrader 5 اندروید وصل نیست.**
- داده‌ها از API عمومی [biquote](https://biquote.io/docs/) گرفته می‌شوند و ممکن است با نرخ بروکر تفاوت داشته باشند.
- RSI(14)، MACD(12,26,9)، شکست خطوط روند مبتنی بر پیوت‌ها روی کندل بسته بررسی می‌شود.
- ربات هیچ سفارش خرید یا فروشی ارسال نمی‌کند.
- پاسخ‌ها و هشدارها فقط زمانی کار می‌کنند که برنامه Termux گوشی در حال اجرا و اینترنت وصل باشد.
- برای امنیت، کاربر اول باید یک کد فعال‌سازی تصادفی از پنجره Termux وارد کند؛ دیگران دسترسی ندارند.

## راه‌اندازی با گوشی اندروید

1. در تلگرام وارد [@BotFather](https://t.me/BotFather) شو و با دستور /newbot یک ربات بساز. توکن ربات را محرمانه نگه‌دار و در چت یا GitHub نفرست.
2. [Termux رسمی از F-Droid](https://f-droid.org/packages/com.termux/) را نصب کن.
3. دستورهای زیر را در Termux اجرا کن:

```bash
pkg update -y && pkg install -y python curl
mkdir -p ~/marketbot && cd ~/marketbot
curl -fsSL https://raw.githubusercontent.com/mohsenezare/money/main/telegram-bot/bot.py -o bot.py
read -rsp "Paste your BotFather token: " TELEGRAM_BOT_TOKEN; echo; export TELEGRAM_BOT_TOKEN
python bot.py
```

4. در ترموکس خطی شبیه FIRST SETUP: send /claim XXXXXXX چاپ می‌شود. کد واقعی را بردار.
5. وارد چت ربات خودت در تلگرام شو و دستور /claim XXXXXXX را بفرست؛ Xها را با کد ترموکس عوض کن.
6. حالا از دکمه‌های ربات یا دستورهای زیر استفاده کن.

توکن فقط در متغیر محیطی همان نشست استفاده می‌شود؛ رمز MT5 یا LiteFinance لازم نیست. پایگاه داده bot_state.sqlite3 در پوشه ربات ساخته می‌شود؛ آن را حذف نکن چون مالک و تنظیمات هشدار را نگه می‌دارد. بهتر است محدودیت باتری Termux را برداری، ولی کارکرد ۲۴ ساعته تضمین نمی‌شود.

## فرمان‌های تلگرام

| دستور | کاربرد |
|---|---|
| /start | منوی اصلی |
| /price XAUUSD | آخرین قیمت طلا و زمان آن |
| /price EURUSD | آخرین قیمت یورو به دلار |
| /price BTCUSD | آخرین قیمت بیت‌کوین |
| /analyze XAUUSD 5m | محاسبه RSI، MACD و شکست خط روند روی کندل‌های بسته |
| /analyze EURUSD 15m | تحلیل تایم‌فریم ۱۵ دقیقه |
| /watch XAUUSD 5m | ثبت بررسی شکست و هشدار خودکار |
| /unwatch XAUUSD 5m | لغو بررسی همین نماد |
| /watches | نمایش هشدارهای فعال |
| /source | توضیح درباره منبع نرخ |
| /help | راهنما |

تایم‌فریم‌ها: 1m، 5m، 15m، 1h.

بررسی هشدار حدود هر ۶۰ ثانیه است، نه تضمین آنی. روی داده قدیمی هشدار صادر نمی‌کند و برای جلوگیری از تکرار هشدار از SQLite استفاده می‌کند.

## حل مشکل

- خطای توکن: دوباره توکن را از BotFather در Termux وارد کن.
- خطای conflict: از یک توکن در دو برنامه استفاده نکن؛ اگر همان توکن روی سرور وب‌هوک تنظیم شده، ابتدا آن را قطع کن.
- خطای دریافت قیمت: در مرورگر گوشی https://biquote.io/api/XAUUSD را باز کن. اگر JSON دریافت نکردی، مشکل از منبع داده یا اتصال اینترنت است، نه از فرمول اندیکاتورها.
- در تعطیلات بازار ممکن است قیمت آخرین تیک نمایش داده شود؛ ربات آن را با وضعیت بسته یا قدیمی مشخص می‌کند.

## تست توسعه‌دهنده

```bash
cd telegram-bot
python -m unittest -v test_bot.py
```

تست‌ها پاسخ‌های نمونه و منطق را بررسی می‌کنند؛ اتصال واقعی اینترنت و کارکرد گوشی باید هنگام راه‌اندازی بررسی شود.
