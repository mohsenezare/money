# اتصال امن LiteFinance به Market Analyzer از گوشی اندرویدی

> این برنامه و metatraderapi.net متعلق به LiteFinance یا MetaQuotes نیستند. قبل از وارد کردن اطلاعات حساب در ارائه‌دهنده واسط، هزینه‌ها و سیاست حریم خصوصی آن را بررسی کنید.

## پیش‌نیاز

- حساب MT5 لایت‌فاینانس که روی اندروید کار می‌کند
- نام دقیق **Broker Server** و شناسه ورود MT5 (**Login**)
- رمز Investor اختصاصی (بدون اجازه معامله)
- اشتراک فعال MetaTrader API (طبق تعرفه ۲۴ اکتبر ۲۰۲۶ حدود ۱۴ دلار در ماه به‌ازای یک seat؛ آزمایش رایگان ندارد)

## گام‌های راه‌اندازی

1. در MT5 اندروید، از بخش **Manage Accounts** سرور حساب و شماره Login را مشاهده کن.
2. در بخش **Accounts → menu → Change Password**، گزینه **Change Investor Password** را بزن و رمز فقط‌خواندنی مجزا بساز. رمز اصلی معامله‌گر را در جایی به اشتراک نگذار.
3. با مرورگر گوشی به `https://app.metatraderapi.net` برو. حساب کاربری بساز، اشتراک را فعال کن، سپس در **Accounts** یک حساب MT5 با سرور دقیق، Login و رمز **Investor** متصل کن. اگر Investor توسط ارائه‌دهنده پذیرفته نشد، **بدون بررسی بیشتر رمز Master را جایگزین نکن**.
4. پس از فعال شدن اتصال، شناسه حساب **UUID** را بردار. برای اتصال به اپلیکیشن از کلید **readOnly=true** و **accountScoped=true** استفاده کن. ایجاد چنین کلیدی طبق مستندات سرویس با API مدیریت از مسیر `POST /v1/seats/{accountId}/keys` با بدنه `{"label":"mobile-market-analyzer","accountScoped":true,"readOnly":true}` پشتیبانی می‌شود؛ کلید مدیریتی را هرگز داخل برنامه اندروید قرار نده. اگر این کار با داشبورد مقدور نبود، از راهنمای خود سرویس یا پشتیبانی‌اش کمک بگیر.
5. Market Analyzer را نصب و اجرا کن. در بخش تنظیمات اتصال، **کلید محدودشده** و Account UUID را وارد کن.
6. نام نمادهای واقعی را با نام نمایش‌داده‌شده در MT5 برابر کن. برای مثال، `XAUUSD` ممکن است پسوند بروکری داشته باشد.
7. از `CheckConnect` و `GetQuote` سرویس برای بررسی درست بودن اتصال استفاده کن؛ به خاطر بسته بودن بازار یا تعطیلی آخر هفته ممکن است قیمت جدیدی دریافت نشود.

## اصول امنیتی

- رمز MT5، کلید مدیریتی MetaTrader API و هر API Key محرمانه را در چت، اسکرین‌شات یا GitHub عمومی منتشر نکن.
- کلید قابل‌استفاده در گوشی را **account-scoped + read-only** تنظیم کن و در صورت افشا فوراً باطل/تعویض کن.
- رمز Investor هم اطلاعات معاملاتی و موجودی را افشا می‌کند؛ فقط به ارائه‌دهنده‌ای که اعتماد داری بده.
- برای آزمایش اولیه بهتر است یک حساب **دمو** با رمز Investor به سرویس وصل شود (اشتراک سرویس همچنان لازم است).
- برنامه معاملات ارسال نمی‌کند، ولی امنیت آن در حالت اتصال مستقیم به یک سرویس خارجی به امنیت کلید و گوشی وابسته است.
- تنها اتصال MT5 اندروید به بروکر، API عمومی نمی‌سازد. اگر اشتراک واسط نمی‌خواهی، باید منبع قیمت دیگری انتخاب شود که لزوماً با قیمت LiteFinance یکسان نیست.
